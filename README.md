# 🦚 Janmashtami – Divine Particle Reveal

A creative Janmashtami animation made using **Python, OpenCV and NumPy**.

The animation starts with glowing particles forming the artwork, then transforms into a clean black-and-white sketch, and finally transitions smoothly into the colored artwork.

## ✨ Animation

The project has the following animation sequence:

1. ⚫ Black screen intro
2. ✨ Particles fly in and form the sketch
3. ✏️ Particles transform into the clean line-art
4. 🖼️ Black-and-white sketch is displayed
5. 🎨 Sketch smoothly transitions into the colored artwork
6. 🦚 Final colored artwork is displayed

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
